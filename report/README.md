# Overleaf Package — ATML PA4 Report

Upload `ATML_PA4_Report_Overleaf.zip` (or the contents of this directory: `main.tex`, `references.bib`, `neurips_2019.sty`, and `figures/*.pdf`) to a new Overleaf project and set `main.tex` as the main document.

- **Template:** Course NeurIPS 2019 single-column format (`neurips_2019.sty`, `[final]` with `@notice` cleared), matching PA1–PA3.
- **Length:** Calibrated for **8 pages of main content** (Sections 1–5), with References starting on Page 9 and Appendices A–D following References.
- **Reproducibility:** All 7 clean vector PDF figures in `figures/` (3 main + 4 appendix) are deterministically generated from `results/` via `python report/make_figures.py`.
- **Pre-submission check:** Compile once in Overleaf (pdfLaTeX) to confirm the main body finishes cleanly on Page 8 and all floats place neatly.
